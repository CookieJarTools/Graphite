# Taskbar

A floating, centred taskbar: the native taskbar restyled with the Windhawk Taskbar Styler mod.

- Floats `space-2` above the bottom edge, `taskbar-height`, `radius-lg`, `surface-200` acrylic, 1px `glass-edge`, `shadow-card`.
- Left: Home button (search glyph) that opens HomeSearch.
- Centre: running windows as pills, 24px app icon plus a short label in `strip` style. Focused window `surface-300` fill and `ink`; others `ink-muted`. A 4px `accent` dot under a window that wants attention.
- Right: tray (network, volume, battery) as 16px `ink-muted` glyphs, then the time and date in `strip` style.
- Auto-hides when a window is maximised.
